# 游玩机制与设置

[返回 README](../README.zh-CN.md) | [English](./gameplay.md)

## 输入与键位

游玩时按**上/下方向键**临时加快或减慢滚速。可在 **设置 → Key Bindings → osu!BMS** 中重新绑定。

按键会播放对应轨道的按键音。

皿有两个方向，分别绑定为**皿**和**反向转盘**。任意方向都可以击打普通皿音符。
长皿需要在头部按下一个方向，并按照[长音符规则](#长音符)完成尾部操作。

| 布局 / 玩家侧 | 皿 | 反向转盘 |
|---------------|----|--------|
| 5K / 7K，1P | 左 Shift | 左 Ctrl |
| 5K / 7K，2P 布局 | 右 Shift | 右 Ctrl |
| 双人布局，P1 | 左 Shift | 左 Ctrl |
| 双人布局，P2 | 右 Shift | 右 Ctrl |

使用键盘游玩时，请为两个方向分别设置顺手的按键。CN 和 HCN 长皿需要在尾部附近按下相反方向来完成尾判定。
**Auto Scratch** 会自动完成皿音符、长皿保持和尾部反向操作。

## 判定与计分

**判定等级：**判定窗口遵循 beatoraja。下表以默认判定设置下的 **7K 键盘轨道、`#RANK 2`（Normal）**为例。
负数表示偏早，正数表示偏晚；每次按键取所在窗口中最好的判定。

| 名称         | EX 分 | 连击      | RANK 2 (Normal) 窗口    |
|------------|------|---------|-----------------------|
| **PGREAT** | 2    | 保持      | ±15 ms                |
| **GREAT**  | 1    | 保持      | ±45 ms                |
| **GOOD**   | 0    | 保持      | ±112.5 ms             |
| **BAD**    | 0    | 重置      | -165 ms / +210 ms     |
| **POOR**   | 0    | 重置      | 超过 +210 ms 后漏判    |
| **E-POOR** | 0    | 7K 保持   | 音符附近的空击，详见下文 |

7K 键盘轨道从 `#RANK` 0 = Very Hard（±5/15/37.5 ms，BAD -55/+70 ms）到 4 = Very Easy
（±25/75/187.5 ms，BAD -275/+350 ms）。皿轨、长音符尾部、5K 和 PMS 各自使用对应的判定窗口。
`#DEFEXRANK` 和无编号的 `#EXRANK` 以百分比设置初始判定窗口宽度，`100` 等同 Normal（`#RANK 2`）。
`A0` 通道可在谱面中途应用带编号的 `#EXRANKxx`。

**E-POOR** 是空击产生的扣血判定。在早于 BAD 窗口、距离音符不足 500 毫秒的区间空击，可以触发 E-POOR。
5K 和 7K 中，在已经判定的音符附近再次空击也可能触发 E-POOR。7K 的 E-POOR 保持连击；5K 和 PMS 的 E-POOR 重置连击。

**PMS** 会记录同一音符的首次 BAD 或 E-POOR，并保留音符供玩家在 GOOD、GREAT 或 PGREAT 窗口内补打。
首次失误和成功补打都会保留在成绩中。`#RANK 2` 下，PMS 键盘轨道的窗口为 PGREAT ±20 ms、GREAT ±35 ms、
GOOD ±81.9 ms、BAD ±183 ms。

**分数：** `总 EX 分 / 最大 EX 分 × 1,000,000`

**DJ LEVEL 评级：** S（全 PGREAT）· AAA ≥ 8/9 · AA ≥ 7/9 · A ≥ 6/9 · B ≥ 5/9 · C 其它

### 判定选择算法

在**设置 → BMS → 判定选择算法**中，可设置同一轨道的判定窗口重叠时，本次按键判定哪个音符。
四种策略对应 beatoraja 的 `Combo`、`Duration`、`Lowest` 和 `Score` 算法：

| 选项 | 选择规则 |
|------|----------|
| **连击优先（LR2）**——默认 | 当前候选音符已严格超过 GOOD 的 Slow 边界，且本次按键不早于后一个音符的 GOOD Fast 边界时，改选后者。 |
| **时间差优先（AC）** | 选择与按键时刻最接近的可判定音符；时间差相等时选择较早的音符。 |
| **最早音符优先** | 选择最早可判定的音符，即使后一个音符能得到更好的判定。 |
| **分数优先** | 与连击优先使用相同的换选规则，但将 GOOD 边界替换为 GREAT 边界。 |

例如，7K `#RANK 2` 谱面的同一键盘轨道在 1000 毫秒和 1100 毫秒各有一个音符。若在 1100 毫秒按键，
连击优先或最早音符优先会判定第一个音符，得到 GOOD；时间差优先或分数优先会判定第二个音符，得到 PGREAT。

选择算法适用于普通音符和长音符头部，包括皿轨。各音符的窗口由布局、RANK/EXRANK 和判定窗口 Mod 决定。

算法在每局开始时固定，设置更改从下一局生效。回放使用录制时的算法；此设置加入前的回放沿用原有算法。

### 长音符

长音符模式由谱面以及 **Long Note（L1）**、**Charge Note（L2）**、**Hell Charge Note（L3）** Mod 决定。

| 模式 | 操作方法 | 判定方式 |
|------|----------|----------|
| **LN** | 在头部按下，持续按住至尾部。 | 每根长音符结算一次。保持到尾部时采用头部判定；提前松开时综合头部和松键判定，取较差结果。过早松开会得到 BAD。 |
| **CN** | 在头部按下，在尾部松开。 | 头尾分别判定，各自影响 EX 分、连击和血量。漏掉头部时，头尾各记一次 POOR。 |
| **HCN** | 按 CN 的时机处理头尾，并在主体期间保持按住。 | 头尾分别计分，主体期间按住积累回复、松开积累扣血；失误后重新按住可以回复血量。 |

**CN 和 HCN 长皿**的尾部操作是按下与头部相反的方向。可以在尾部判定窗口内先松开原方向，再按下反方向，
尾判定取反方向按下的时机；也可以保持原方向按键，同时按下反方向。提前反向会立即结算尾部，因此应将反向操作对准尾部。
在尾部窗口之前松开原方向会得到 POOR。普通 **LN 长皿**则保持头部方向至尾部；提前松开该方向会结算掉落判定。

HCN 的回复和扣血随持续时间积累，按住与松开的时间会相互抵消。持续按住或松开超过 200 毫秒后开始产生血量变化，
随后大约每 200 毫秒变化一次。尾部得到 GOOD 或更好判定时，剩余主体继续回复；漏掉头部后，仍可通过按住主体回复血量。
提前成功完成尾判定后，HCN 的剩余主体会贴着判定线逐渐缩短，并在尾部到达判定线时消失。

PMS 对提前松开、原本会得到 BAD 或更差判定的长音符提供 **200 毫秒补救时间**。
在此期间重新按下即可继续保持；到期后按最初松开的时机结算。

### 暂停与继续

暂停时，已经开始且尾部仍待判定的长音符会立即完成尾判定，以暂停时刻作为松键时刻；提前暂停可能得到 BAD 或 POOR。
已处于 PMS 补救时间内的松键按原松键时刻结算。通过暂停完成的 HCN，其主体血量变化在此结束。

继续时会提供最长 **5 秒的准备回退**，并保留已获得的判定。播放回到暂停位置后，接着处理剩余音符。
保存的成绩会带有 **Paused（PA）** 标记。

## 血量

通过 Mod 选择血条：6 种常规类型（Groove 或 Survival）和 3 种段位类型，默认使用 Normal。

> [!NOTE]
> 血量回复、伤害和通关线遵循 **beatoraja**。所选血条决定失误对通关的影响。

| Mod         | 缩写     | 类型   | 回复方式          | 初始 HP | 通关    | 血条         |
|-------------|--------|------|-----------------|-------|-------|------------|
| Assist Easy | **E2** | 难度降低 | 按谱面 TOTAL 分配 | 20%   | ≥ 60% | Groove（动态） |
| Easy        | **E1** | 难度降低 | 按谱面 TOTAL 分配 | 20%   | ≥ 80% | Groove（动态） |
| Normal      | *(默认)* | —    | 按谱面 TOTAL 分配 | 20%   | ≥ 80% | Groove（动态） |
| Hard        | **H1** | 难度增加 | 按谱面少量回复 | 100%  | 存活    | 固定红色       |
| EX Hard     | **H2** | 难度增加 | 按谱面少量回复 | 100%  | 存活    | 固定紫色       |
| Hazard      | **H3** | 难度增加 | 靠初始血量坚持 | 100%  | 存活    | 固定金色       |
| Class       | **C1** | 段位     | 每次固定回复 | 100%  | 存活    | 固定红色       |
| EX Class    | **C2** | 段位     | 每次固定回复 | 100%  | 存活    | 固定紫色       |
| EX Hard Class | **C3** | 段位   | 每次固定回复 | 100%  | 存活    | 固定金色       |

- **Groove 血量**（E2/E1/Normal）：从 20% 开始，最低保留 2%，整首曲目中都可以继续回复，结束时需达到通关线。
  血条颜色按阈值动态变化：红（< 20%）→ 黄（< 通关线）→
  绿（≥ 通关线）。
- **Survival 血量**（H1/H2/H3）：从 100% 开始，降至 0% 即失败。Hard 和 EX Hard 可通过成功击打回复；
  Hazard 需要靠初始血量坚持到结束。各血条使用固定颜色。
- **段位血条**（C1/C2/C3）：跨曲目保留血量的 Survival 血条，降至 0% 即段位失败，颜色为红、紫或金色。
  所选常规血条会映射到对应的 Class 档位。
- Hard（H1）有 **guts 保护**：低于各血量阈值时减少伤害（低于 50% → ×0.8、低于 40% → ×0.7、……、低于 10% → ×0.4）。
- `#TOTAL` 控制血量回复。谱面的回复量按计分音符分配：普通 LN 计一次，CN 和 HCN 的头尾分别计入。
  谱面省略 `#TOTAL` 时，游戏根据布局和音符数量选择默认回复量。
- 地雷经过判定线时按住对应轨道，会触发谱面设定的伤害；皿轨任意方向按住都可触发。
  地雷伤害遵循血条下限：最高伤害地雷也会让 Groove 血条保留 2%，Survival 血条则可能降至 0% 并失败。

## 灯（Lamp）

曲目面板、段位曲目面板和段位卡片用**通关灯**标记最佳成绩。颜色、闪烁和顺序遵循 **beatoraja** 默认皮肤的
`lamp.png`，沿用 LR2 约定。从低到高依次为：

| 灯        | 填充色   | 闪烁色   | 含义                              |
|----------|--------|-------|---------------------------------|
| NO PLAY  | `#282C30` | —     | 没有成绩记录                          |
| FAILED   | `#E92F0A` | `#0F0300` | 未通过；以 60 ms 周期闪烁               |
| L-ASSIST | `#DDA2DF` | —     | 使用 **Assist Easy** 血条通过          |
| EASY     | `#56CA43` | —     | 使用 Easy 血条通过                    |
| NORMAL   | `#F5C758` | —     | 使用 Normal 血条通过                  |
| HARD     | `#F8F7F5` | —     | 使用 Hard 血条通过                    |
| EX-HARD  | `#EFFD09` | `#FD0909` | 使用 EX-Hard 或 Hazard 血条通过；以 60 ms 周期闪烁 |
| FULL COMBO | `#FFFFFF` | `#09FAFD` | 全连；以 60 ms 周期闪烁                 |
| PERFECT  | `#FFFFFF` | `#3FFF4D` | 仅 PGREAT + GREAT；以 60 ms 周期闪烁    |
| MAX      | `#FFFFFF` | `#FFEB42` | 全 PGREAT；以 60 ms 周期闪烁            |

面板显示与当前 Mods 匹配的最高通关灯和评级。使用更简单的血条通关不会让已有的灯降级。

降低难度时仍会显示在更困难条件下获得的灯；提高难度时则隐藏在更简单条件下获得的灯。
筛选通关灯时，只有 Double Time 会被视为提高难度。

beatoraja 将谱面辅助（**ASSIST**，深紫）与 Assist Easy 血条（**L-ASSIST**）区分。
本规则集没有谱面级辅助选项，因此 Assist Easy 通关获得 L-ASSIST 灯，不产生 ASSIST 灯。

### 视觉偏移校准

视觉偏移调整音符在画面上到达判定线的时机。LN 尾视觉偏移让尾部提前显示，使长音符看起来更短。

手动进行的本地游玩在积累至少 50 个有效时机判定后，会根据击打误差中位数生成建议。
可在 BMS 设置中手动应用最近建议的平均值，或开启**自动调整视觉偏移**，在每次有效游玩后应用新建议。

## 选歌搜索

选歌搜索框支持以下 BMS 筛选选项：

| 筛选项 | 简写 | 值 |
|--------|------|----|
| `stars` | `star`、`sr` | osu! 星级难度 |
| `keys` | `k`、`key` | 不包含皿的可玩按键数；例如 `k=7` 会搜索 7K + 皿谱面 |
| `source` | `src` | 谱面来源路径中包含的文本 |
| `ln` | `lns` | LN 物件占总物件的百分比，范围为 0–100 |
| `scratch` | `sc` | 皿轨物件占总物件的百分比，范围为 0–100 |
| `table` | `tb` | 难度表名称或符号 |
| `level` | `lv` | 难度表等级 |

数值筛选支持 `=`、`!=`、`<`、`<=`、`>` 和 `>=`，例如 `ln>=25` 或 `sc<10`。按键数等值筛选还支持逗号分隔，
例如 `keys=5,7`。
